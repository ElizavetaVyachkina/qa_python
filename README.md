# qa_python
# Проект: Книжный каталог (Тестирование)

## Описание
Проект предназначен для отработки навыков автоматизированного тестирования. В рамках задания разработан набор тестов для класса BooksCollector, который управляет коллекцией книг, их жанрами и избранным.

## Покрытие тестами
Ниже представлен список реализованных тестов, разделенный по функциональным блокам для удобства.

### Блок 1: Добавление книг (Метод add_new_book)

1. Добавление новой книги с пустым названием: Проверка, что метод игнорирует добавление книги с пустым именем.  
2. Добавление книги с названием длиннее 40 символов: Проверка, что метод игнорирует добавление книги, превышающей лимит длины.  
3. Добавление валидного значения: Проверка, что после добавления книг метод get_books_genre возвращает словарь корректной длины равной добавленным книгам.  

### Блок 2: Работа с жанрами (Методы set_book_genre, get_book_genre)

4. Установка валидного жанра: Проверка успешной установки допустимых жанров ('Фантастика', 'Детективы', 'Мультфильмы').  
5. Установка невалидного жанра: Проверка, что попытка установить жанр, отсутствующий в списке допустимых (например, 'Роман'), игнорируется.  
6. Установка жанра несуществующей книге: Проверка, что метод не вызывает ошибку при попытке изменить жанр книги, которой нет в коллекции.  
7. Получение жанра по имени: Проверка, что метод get_book_genre возвращает правильный жанр для существующей книги.  
8. Получение None для несуществующей книги: Проверка, что метод возвращает None, если запрошенная книга отсутствует в коллекции.  
9. Фильтрация по жанру (существующие книги): Проверка, что метод get_books_with_specific_genre возвращает список книг с указанным жанром.  
10. Фильтрация по жанру (отсутствие книг): Проверка, что метод возвращает пустой список, если книг с указанным жанром нет.  
11. Фильтрация по невалидному жанру: Проверка, что метод возвращает пустой список при запросе жанра, которого нет в системе.  
12. Проверка типа данных: Проверка, что метод get_books_genre возвращает объект типа dict (словарь).  

### Блок 3: Фильтрация книг для детей (Метод get_books_for_children)

13. Получение списка подходящих книг: Проверка, что метод возвращает книги с жанрами, не требующими возрастного рейтинга ('Фантастика', 'Мультфильмы', 'Комедии').  
14. Получение пустого списка: Проверка, что метод возвращает пустой список, если все книги имеют жанры с возрастным рейтингом ('Ужасы', 'Детективы') или отсутствуют.  

### Блок 4: Работа с избранным (Методы add_book_in_favorites, remove_from_favorites)

15. Добавление книги в избранное: Проверка успешного добавления существующей книги в список избранного.  
16. Добавление дубликата: Проверка, что повторное добавление одной и той же книги не создает дубликатов в списке.  
17. Добавление несуществующей книги: Проверка, что попытка добавить в избранное книгу, которой нет в коллекции, игнорируется.  
18. Удаление книги из избранного: Проверка успешного удаления существующей книги из списка избранного.  
19. Удаление несуществующей книги: Проверка, что попытка удалить книгу, которой нет в избранном, не вызывает ошибку.  
20. Проверка типа данных избранного: Проверка, что метод получения списка избранного возвращает объект типа list (список).  
21. Получение списка избранных книг: Проверка корректности работы метода по выводу текущего списка избранного.
